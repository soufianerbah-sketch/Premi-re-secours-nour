# لعبة الإسعافات الأولية 🚑

لعبة تعليمية للإسعافات الأولية — المؤسسة الخاصة للشبه الطبي بير العاتر (ملائكة الرحمان)

**إنجاز: عبدو نور الإسلام**

## المميزات
- 4 مراحل، 20 سؤالاً
- إجابة صحيحة: فقاعات قلوب 💖 — إجابة خاطئة: إيموجي الحزن 😢
- صورة توضيحية لكل سؤال، وزر «التالي» للتنقل
- النتيجة النهائية بالنسبة المئوية
- شعار المدرسة في الصفحة الرئيسية وكأيقونة للتطبيق

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub، ثم ارفع كل محتويات هذا المجلد (مع الملف المخفي `.nojekyll`).
2. من **Settings ← Pages** اختر الفرع `main` والمجلد `/ (root)` ثم **Save**.
3. بعد دقيقة يعمل الرابط: `https://اسم-المستخدم.github.io/اسم-المستودع/`

## تثبيت التطبيق على الهاتف (أيقونة بشعار المدرسة)
- **أندرويد (Chrome):** افتح الرابط ← قائمة ⋮ ← «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
- **آيفون (Safari):** افتح الرابط ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- **الحاسوب (Chrome/Edge):** أيقونة التثبيت في شريط العنوان.

## الملفات
- `index.html`: اللعبة كاملة (الصور والشعار مضمنة داخله)
- `manifest.webmanifest` و `sw.js` و `icons/` و `apple-touch-icon.png`: لتثبيت التطبيق بأيقونة الشعار ويعمل بدون إنترنت بعد أول فتح
- `assets/`: الشعار وصور الأسئلة (`q1.jpg` … `q20.jpg`)
